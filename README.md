# 🏗️ Gerenciador de Relatórios de Obras GRE (SEDUC-PI)

Aplicação web moderna para controle, monitoramento e consolidação de relatórios de obras escolares das Gerências Regionais de Educação (GRE / SEDUC-PI), com suporte a pactuação, persistência local e gerador automatizado de mensagens para WhatsApp.

## 🚀 Funcionalidades

- **Controle por GRE e Município**: Visualização e edição rápida do status das obras em cada região.
- **Campos Editáveis em Tempo Real**:
  - Escola / Unidade Escolar
  - Empresa executora
  - Status da Obra (Em andamento, Paralisada, Concluída, A iniciar)
  - Percentual de execução (%)
  - Última medição e data da última vistoria
  - Observações e pendências
- **Gerador Automático para WhatsApp**: Gera relatório formatado com emojis, marcadores e destaques com botão de cópia com 1 clique.
- **Persistência de Dados**: Armazena as alterações automaticamente no navegador (`localStorage`), sem perda de dados ao atualizar a página.
- **Filtros e Busca**: Busca instantânea por escola, cidade ou empresa, além de filtros por GRE.
- **Layout Responsivo**: Otimizado para computadores, tablets e smartphones (Tailwind CSS Dark Mode).

## 💻 Como Usar

Abra o arquivo `index.html` em qualquer navegador ou acesse a versão online hospedada na Vercel.
